# 2048 Implementation Plan

**Goal:** 交付可在电脑与手机游玩的中文 2048 及测试、说明。

**Architecture:** 纯规则与浏览器界面分离，所有输入共享一次移动入口，localStorage 容错保存。移动记录驱动动画，数据决定最终画面。

**Tech Stack:** HTML、CSS、JavaScript ES modules、Vite、node:test、Playwright。

## Global Constraints

- 4×4 经典规则，单次不可连锁合并，无效移动不生成数字。
- 键盘、WASD、手机滑动；首次 2048 可继续；自动存档与最高分。
- 实际实现与验收在当前会话完成；不创建子代理或外部托管资源。

## 验证用例

向左：[2,2,2,2] → [4,4,0,0]，得分 8；[2,2,4,0] → [4,4,0,0]，得分 4。
向右：[2,2,2,0] → [0,0,2,4]；上下用竖直固定棋盘验证。
存档使用 Map 实现 Storage 接口，直接序列化并重新加载；抛出 SecurityError 时返回安全默认值。
浏览器通过 localStorage 放入固定局面，触发真实键盘与触摸事件后检查数字、分数及存档；不添加产品专用测试接口。
